### 1. Remove Outermost Parentheses

- Platform: LeetCode
- Difficulty: Easy
- Topic: String, Stack, Bracket Sequences

### Problem Link
https://leetcode.com/problems/remove-outermost-parentheses/description/

### Complexity

- Time: O(n)
- Space: O(n)

### Python Solution

```python
class Solution:
    def removeOuterParentheses(self, s: str) -> str:
        ans = []
        depth = 0

        for ch in s:
            if ch == '(':
                if depth > 0:
                    ans.append(ch)
                depth += 1
            else:
                depth -= 1
                if depth > 0:
                    ans.append(ch)

        return "".join(ans)
```
