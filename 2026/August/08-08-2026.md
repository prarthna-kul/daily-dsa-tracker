### 1. Reverse Integer

- Platform: LeetCode
- Difficulty: Medium
- Topic: Math

### Problem Link
https://leetcode.com/problems/reverse-integer/description/

### Python Solution

```python
class Solution:
    def reverse(self, x: int) -> int:
        ans=0
        a=0
        if x<0:
            a=-1
            x=x*-1
        while x>0:
            r=x%10
            x=x//10
            ans=ans*10+r
        if a==-1:
            ans=ans*-1
        if ans not in range(-(2**31),2**31):
            return 0
        return ans
```
