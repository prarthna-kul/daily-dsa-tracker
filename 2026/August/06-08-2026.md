### 1. Smallest Divisible Digit Product I

- Platform: LeetCode
- Difficulty: Easy
- Topic: Math

### Problem Link
https://leetcode.com/problems/smallest-divisible-digit-product-i/description/

### Python Solution

```python
class Solution:
    def smallestNumber(self, n: int, t: int) -> int:
        while True:
            x = n
            prod = 1

            while x > 0:
                prod *= x % 10
                x //= 10

            if prod % t == 0:
                return n

            n += 1
```
