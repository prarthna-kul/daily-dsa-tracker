### 1. Longest Consecutive Sequence

- Platform: LeetCode
- Difficulty: Medium
- Topic: Array, Hash Table

### Problem Link
https://leetcode.com/problems/longest-consecutive-sequence/

### Complexity

- Time: O(n)
- Space: O(n)

### Python Solution

```python
class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        if not nums:
            return 0
        nums=set(nums)
        nums=list(nums)
        nums.sort()
        c=1
        ans=1
        for i in range(len(nums)-1):
            if nums[i+1]==nums[i]+1:
                c+=1
                ans=max(c,ans)
            else:
                c=1
        return ans
```
