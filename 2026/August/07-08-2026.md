### 1. Add Binary

- Platform: LeetCode
- Difficulty: Easy
- Topic: Math, String, Bit Manipulation

### Problem Link
https://leetcode.com/problems/add-binary/description/

### Python Solution

```python
class Solution:
    def addBinary(self, a: str, b: str) -> str:
        ans=bin(int(a,2)+int(b,2))
        return ans[2:]
```

### 2. Set Matrix Zeroes

- Platform: LeetCode
- Difficulty: Medium
- Topic: Array, Hash Table

### Problem Link
https://leetcode.com/problems/set-matrix-zeroes/

### Complexity

- Time: O(m*n)
- Space: O(m+n)

### Python Solution

```python
class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """
        m = len(matrix)
        n = len(matrix[0])
        rows = set()
        cols = set()
        for i in range(m):
            for j in range(n):
                if matrix[i][j] == 0:
                    rows.add(i)
                    cols.add(j)
        for i in range(m):
            for j in range(n):
                if i in rows or j in cols:
                    matrix[i][j] = 0
```
