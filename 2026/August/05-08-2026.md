### 1. Maximum Product of Two Digits

- Platform: LeetCode
- Difficulty: Easy
- Topic: Math, Sorting

### Problem Link
https://leetcode.com/problems/maximum-product-of-two-digits/

### Python Solution

```python
class Solution:
    def maxProduct(self, n: int) -> int:
        l=[]
        l2=list(str(n))
        for i in range(len(l2)):
            for j in range(i+1,len(l2)):
                l.append(int(l2[i])*int(l2[j]))
        return max(l)
```

### 2. Maximum Subarray

- Platform: LeetCode
- Difficulty: Medium
- Topic: Array

### Problem Link
https://leetcode.com/problems/maximum-subarray/description/

### Python Solution

```python
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        ans=-9999999
        s=0
        for i in range(len(nums)):
            s+=nums[i]
            if s>ans:
                ans=s
            if s<0:
                s=0
        return ans
```
