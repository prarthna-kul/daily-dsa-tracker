### 1. Find Missing Elements

- Platform: LeetCode
- Difficulty: Easy
- Topic: Array

### Problem Link
https://leetcode.com/problems/find-missing-elements/description/

### Complexity

- Time: O(nlogn+kn) (Worst Case: O(n<sup>2</sup>))
- Space: O(1)

### Python Solution

```python
class Solution:
    def findMissingElements(self, nums: List[int]) -> List[int]:
        nums.sort()
        s=min(nums)
        l=max(nums)
        ans=[]
        for i in range(s,l+1):
            if i not in nums:
                ans.append(i)
        return ans
```
